Responsive Grid

We can tell Materialize how many columns an element should use on small, medium, and large screens.

s12 m6 l3
s12 m6 l3
s12 m6 l3
s12 m6 l3

s12 = full width on small screens
m6 = half width on medium screens
l3 = one quarter width on large screens
